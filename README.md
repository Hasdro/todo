# Minimalist Todo App

A simple, fast, and elegant todo list web application built with [Next.js](https://nextjs.org), [Tailwind CSS](https://tailwindcss.com), and [Lucide Icons](https://lucide.dev).

## Features

- ✨ **Clean & Focused Design**: Minimalist aesthetic with subtle borders and smooth transitions.
- 🌓 **Dark & Light Mode**: Automatically adapts to system appearance preferences.
- 💾 **Persistent Storage**: Uses browser `localStorage` synchronized with React 19's `useSyncExternalStore`.
- 🔍 **Filtering**: Filter tasks by All, Active, and Completed.
- ⚡ **Zero Configuration**: Ready to run and deploy anywhere.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS
- **Testing**: Vitest & React Testing Library
- **Deployment**: Vercel

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Running Tests

```bash
npm run test
```

## Production Build

```bash
npm run build
```
